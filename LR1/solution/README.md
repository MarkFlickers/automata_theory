# Лабораторная работа № 1

Проект содержит каркас программы минимизации СДНФ методом Квайна–Мак-Класки. Чтение `scale.txt`, проверка входного формата и запись `mdnf.txt` реализованы. Основная логика алгоритма оставлена в местах, помеченных `TODO`.

## Сборка

```powershell
cmake -S . -B build -G Ninja
cmake --build build
```

Исполняемый файл будет создан как `build/lab1.exe`, промежуточные артефакты — в `build/object`.

## Запуск

```powershell
Set-Location build
.\lab1.exe
```

По умолчанию программа читает `scale.txt` и создаёт `mdnf.txt` в текущей папке. Пути можно передать явно:

```powershell
.\lab1.exe путь_к_scale.txt путь_к_mdnf.txt
```
